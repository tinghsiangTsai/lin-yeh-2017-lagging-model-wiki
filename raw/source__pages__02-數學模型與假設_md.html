# 數學模型與假設

這頁回答：控制方程怎麼來、假設有哪些、無因次化之後每個參數代表什麼。

## 幾何與系統假設

- 含水層為洩漏承壓含水層。
- 側向無限延伸。
- 抽水井完全穿透主含水層。
- 含水層厚度為 `b`，弱透水層厚度為 `B'`。
- 抽水井半徑為 `r_w`，套管半徑為 `r_c`。
- 初始狀態下 `s = 0`，且 `∂s/∂t = 0`。
- 外邊界採 `r -> ∞` 時 `s -> 0`。

## 物理上怎麼看這個方程

- 左側第一項：徑向降深曲率與空間擴散。
- 左側第二項：經由弱透水層的洩漏作用。
- 右側：儲水與時間變化。
- `s_q` 與 `s_s` 讓方程帶有類似波動的特性，不再是單純擴散式。

作者也明確指出，這個控制方程已不是傳統擴散方程，而更接近波動型方程。

## 無因次化

論文使用的重要無因次量如下：

| 符號 | 定義 | 意義 |
| --- | --- | --- |
| `s_D` | `4πT s / Q` | 無因次降深 |
| `H_D` | `4πT H / Q` | 無因次井內降深 |
| `r_D` | `r / r_w` | 無因次半徑 |
| `t_D` | `T t / (S r_w²)` | 無因次時間 |
| `C_D` | `r_c² / (2 S r_w²)` | 無因次井筒儲水 |
| `s_qD` | `T s_q / (S r_w²)` | 無因次通量滯後 |
| `s_sD` | `T s_s / (S r_w²)` | 無因次梯度滯後 |
| `j` | `K' / (B' T)` | 洩漏強度參數 |

## 此模型最重要的判斷條件

- `s_q = s_s`：額外滯後行為不顯著。
- `s_q < s_s`：結構互制主導。
- `s_q > s_s`：慣性效應主導。
