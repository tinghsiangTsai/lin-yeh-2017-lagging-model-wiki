解析解與方法

這頁回答：作者如何解方程，以及新模型和雙重孔隙模型之間是什麼關係。

求解策略

作者分兩條路徑求解。

1. 含井筒儲水時

  • 把無因次控制方程做 Laplace 轉換。
  • 將問題化為含修正 Bessel 函數 I0、K0 的常微分方程。
  • 利用內外邊界條件求得 Laplace 域降深解。

Laplace 域結果的核心形式可整理為：

s ‾ D = 2 K 0 ( k r D ) C D p 2 K 0 ( k ) + k p ( 1 + C D p S k ) K 1 ( k )

其中 k 由 p、j、s_qD、s_sD 組成，反映洩漏與滯後共同作用。

2. 忽略井筒儲水與井半徑時

  • 先做 Laplace 轉換。
  • 再用 Weber 轉換回到時間域。
  • 得到可直接分析 s_qD、s_sD 影響的解析積分式。

作者在文中也說明，當 s_qD = s_sD = 0，解可退化為 Hantush 與 Jacob 的經典洩漏承壓含水層解。

與經典模型的關係

可退化為 Hantush-Jacob 解

若：

  • 不考慮滯後，即 s_qD = 0、s_sD = 0
  • 再取極小井半徑近似

新模型會回到傳統的洩漏承壓含水層抽水解。這表示新模型不是推翻舊模型，而是把舊模型包在更一般的框架內。

與雙重孔隙模型的數學相似性

論文將雙重孔隙模型中 fracture 與 matrix 的方程整理後，得到與本研究控制方程近似的形式，並對應出：

ss = Sm b
S = Sf + Sm
sq = Sm Sf b (Sf + Sm)

這代表：

  • 數學上，新模型與雙重孔隙模型非常接近。
  • 物理上，雙重孔隙模型強調 fracture 與 matrix 的交換。
  • 本文模型強調滯後響應本身，可解讀為慣性與結構互制共同控制。

作者強調的新模型優勢

  • 雙重孔隙模型常隱含 s_q < s_s 的限制。
  • 本文模型可描述 s_q > s_s 的慣性主導情況。
  • 因此對裂隙地下水流的適用範圍更廣。

方法上的實務意義

從抽水試驗判釋的角度，這篇論文提供的不只是新解，而是多了兩個可估參的時間尺度：

  • s_q：水流慣性或快速反應時間尺度
  • s_s：結構互制或非互連空間造成的延遲時間尺度

這讓抽水曲線中「早期偏慢」與「中期平坦」有了更直接的參數化表達。
