資料來源與檔案說明

這頁回答：本 wiki 的原始材料在哪裡、各資料夾做什麼、如何重建網站。

原始資料

  • 原始論文 PDF：raw/Lin_Yeh_2017_lagging_model.pdf
  • PDF 抽取文字：raw/Lin_Yeh_2017_lagging_model.txt

資料來源說明

  • PDF 來源為工作目錄中的原始論文檔案。
  • txt 由 scripts/extract_pdf_text.py 自 PDF 逐頁抽字產生。
  • 本 wiki 各頁內容由 PDF 內文整理而成，屬於研究筆記與知識整理。

檔案夾說明

路徑用途
raw/保留原始 PDF 與抽字結果
pages/主題式 Markdown 頁面
scripts/抽字、建站、啟動 localhost
site/產生後的靜態網站

如何重建

  1. 執行 python scripts/extract_pdf_text.py
  2. 執行 python scripts/build_site.py
  3. 執行 python scripts/serve_site.py
  4. 以瀏覽器開啟 localhost 位址

raw 索引頁

site/raw/index.html 不是目錄列表，而是由建站腳本主動生成的說明頁，方便直接閱讀：

  • 原始 PDF
  • 抽取文字
  • 各 Markdown 原始碼對應頁

查看對應 Markdown

每一個網站頁面側欄都有 查看對應 Markdown 連結，會打開 site/raw/source__...html，用來對照：

  • 原始 Markdown 內容
  • 原站頁面顯示結果
