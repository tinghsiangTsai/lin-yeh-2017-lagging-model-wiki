數學模型與假設

這頁回答：控制方程怎麼來、假設有哪些、無因次化之後每個參數代表什麼。

幾何與系統假設

  • 含水層為洩漏承壓含水層。
  • 側向無限延伸。
  • 抽水井完全穿透主含水層。
  • 含水層厚度為 b，弱透水層厚度為 B'。
  • 抽水井半徑為 r_w，套管半徑為 r_c。
  • 初始狀態下 s = 0，且 ∂s/∂t = 0。
  • 外邊界採 r -> ∞ 時 s -> 0。

傳統 Darcy 定律

論文先從徑向 Darcy 定律開始：

qr(r, t) = -K ∂s(r, t) ∂r

這個式子意味著通量與梯度同步。

廣義 Darcy 定律

作者改寫為：

qr(r, t + sq) = -K ∂s(r, t + ss) ∂r

經一階 Taylor 展開後，可得到含 s_q 與 s_s 的近似形式。把它代入質量守恆：

( 1 + ss ∂∂t ) ( ∂2s∂r2 + 1r∂s∂r )
− ( 1 + sq ∂∂t ) K′ B′ T s
= S T ( 1 + sq ∂∂t ) ∂s ∂t

物理上怎麼看這個方程

  • 左側第一項：徑向降深曲率與空間擴散。
  • 左側第二項：經由弱透水層的洩漏作用。
  • 右側：儲水與時間變化。
  • s_q 與 s_s 讓方程帶有類似波動的特性，不再是單純擴散式。

作者也明確指出，這個控制方程已不是傳統擴散方程，而更接近波動型方程。

井內邊界條件

定流量與井筒儲水

井壁邊界把抽水量 Q 與井筒儲水一起放進去：

−2π rw T ∂s(rw, t) ∂r = Q + π rc2 dH(t) dt

其中 H(t) 是井內降深。

井皮效應

H(t) = s(rw, t) − Sk rw ∂s(rw, t) ∂r

S_k 為井皮因子。

無因次化

論文使用的重要無因次量如下：

符號定義意義
s_D4πT s / Q無因次降深
H_D4πT H / Q無因次井內降深
r_Dr / r_w無因次半徑
t_DT t / (S r_w²)無因次時間
C_Dr_c² / (2 S r_w²)無因次井筒儲水
s_qDT s_q / (S r_w²)無因次通量滯後
s_sDT s_s / (S r_w²)無因次梯度滯後
jK' / (B' T)洩漏強度參數

此模型最重要的判斷條件

  • s_q = s_s：額外滯後行為不顯著。
  • s_q < s_s：結構互制主導。
  • s_q > s_s：慣性效應主導。
